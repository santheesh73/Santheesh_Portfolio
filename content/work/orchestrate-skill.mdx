## Overview

HackerRank Orchestrate is a solo hackathon for building an AI agent in about 24 hours. This repository has two parts: a field guide to how the event is scored and how to approach it, and a Claude skill that applies the guide during the event.

The skill writes the prompts for your coding agent, checks the reports that come back, and ships scripts that catch the mistakes that cost the most points.

## The approach

> The model describes, code decides.

The model only reports what it observed. Tested code produces every decision.
